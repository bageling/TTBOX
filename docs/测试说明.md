#### ⚠️ 跑验收集合时不要并发干别的重活（2026-09-17 实测）

`ctest` 里含**依赖时序/本地 socket** 的用例（`ipc_*`、`test_license_daemon`、
`test_lifecycle_stress` 等）。机器被其它重活占用时，它们会**大面积超时失败** ——
一次实测：与其它构建/测试并发 ⇒ **26/28 失败、总耗时 20s → 5分25秒**；
空载立复跑 ⇒ **28/28 通过、20.33s**。

**结论：这类批量失败是负载伪影，不是回归。** 遇到大面积红，先**空载复跑一次**再下判断；
报数时必须带"当时机器是否空载"，否则会把伪影当缺陷追（正是本仓反对的"把噪声当信号"）。

```bash
# ❌ 错误：目录形式会在收集期 INTERNALERROR，一条都跑不到
python -m pytest plugins/web/tests -q
```

`test_web_calibration_apply.py` / `test_web_recoil_translation.py` 是**脚本式自测**
（模块级代码 + `sys.exit()`），pytest 收集时会抛 `SystemExit` ⇒ 整个目录
`INTERNALERROR`、**零用例执行**。危险点在于：CI 若只检查"没有 failed"，会把
INTERNALERROR 读成成功 —— 属于本仓一贯反对的"静默跳过"。修法见
`docs/product/TTBOX_WEB_FEATURE_MATRIX.md` 的"待清理项"。

#### 前端纯函数冒烟（无浏览器，用 node 直跑）

`plugins/web/static/app.js` 里有些**纯格式化函数**（输入 → 文案），不需要 DOM，
可以直接抽出来用 node 断言。这不是正式测试框架，而是"改完前端顺手验一下"的手段
—— 2026-09-17 用它抓到过一个真缺陷（`formatModelInputTensor({})` 会拼出
`zp=0 · scale=0`，把"没有数据"伪装成"实测到 zp=0"）。

```bash
# 1) 语法检查（必做，捕获大括号/模板串错误）
node --check plugins/web/static/app.js

# 2) 抽纯函数块 + 断言，喂给 node
python - <<'PY'
import pathlib
s = pathlib.Path('plugins/web/static/app.js').read_text(encoding='utf-8')
block = s[s.index('const MODEL_INPUT_PASS_MODE_LABELS'):s.index('function formatHailoTemperature')]
pathlib.Path('/tmp/app_fmt.js').write_text(block + '''
let bad = 0;
function eq(a, b, w) { if (a !== b) { bad++; console.log('FAIL ' + w + ': ' + JSON.stringify(a)); } }
eq(formatModelInputPassMode('xor_shift128'), 'XOR 快路径（CPU拷贝+XOR）', 'xor label');
eq(formatModelInputPassMode('unknown'), '未运行', 'unknown');
eq(formatModelInputTensor({}), '-', 'empty must not fake zp=0');
console.log(bad === 0 ? 'PASS' : 'FAIL ' + bad);
''', encoding='utf-8')
PY
node /tmp/app_fmt.js
```

⚠️ **不要用"数大括号个数"判断 JS 语法**：`{` 会出现在字符串/模板串/regex 里，
朴素计数必然不等，属**伪检查**（本仓踩过）。语法一律以 `node --check` 为准。

