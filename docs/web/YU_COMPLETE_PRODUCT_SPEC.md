## 01 总览（home-page）

**dashboard-grid 3 列布局**：
```
[预览 320-460px] [运行数据 metrics] [实时锁定 control]
[快速调整 controls 全宽]
[板载资源 hardware 全宽]
```

| 块 | 内容 |
|---|---|
| 激活卡（未激活时 sticky） | 卡密输入 + 激活设备 + 刷新状态 |
| 实时画面 | 低帧预览：MJPEG / 静态帧切换 |
| 运行数据 | 链路延迟 --ms / 采集帧率 --帧/秒 / 检测帧率 --帧/秒 / Hailo温度 -- |
| 目标状态 | 待机 / 主控（当前锁定目标状态） |
| 实时锁定 | 启动 / 开机自启动 开关 |
| 快速调整 | 截取尺寸（chips: 192/256/320/416/640）+ FOV半径 + 截取位置X/Y偏移 + 瞄准点X/Y偏移 + 目标置信度 + 重叠过滤IoU |
| 板载资源 | 硬件状态 + 重启设备 + 关机 |

## 02 热键控制（profiles-page）
热键与类别：
- 热键档案列表（每档案：名称/主热键/副热键/触发方式/灵敏度/瞄准点偏移/备用偏移/FOV缩放/类别过滤掩码）
- 新增热键 / 屏蔽物理按键（复选 X/Y）
- 一键禁用所有热键 + 切换按键 + 当前状态（未禁用）

## 03 移动控制（control-page）
分区页签（01-06 纵向步骤条）：自动标定 / PID / 拉枪曲线 / 持续提前量 / 屏蔽物理移动 / 个性曲线训练
- 自动标定：开始自动标定/取消/清除 + 增益 X/Y + 响应延迟
- PID：移动倍率(sens) + 10 参数（X/Y拉力·预判·积分·刹车·跟随）+ 基础死区 + 目标锁定(转火延迟)
- 开火延迟释放Y轴：开火按键 + 释放延迟 s
- 拉枪曲线：启用 + 曲线强度/随机抖动px/启用距离px
- 持续提前量：进入距离/提前量系数/渐入/渐出/近距离禁用占比
- 屏蔽物理移动：X/Y 复选
- 个性曲线训练：档案选择 + 记录10秒移动日志（联 motion_training 独立页）
- 顶部：恢复本页默认值

## 04 辅助功能（assist-page）
分区页签：压枪 / 自动开火 / 连点 / 自动背闪 / 准星找色
- 压枪：主按键/副按键/触发方式 + 下压强度 + 仅有目标时压枪 + 目标丢失释放ms + 延迟触发压枪/延迟ms + 拟人曲线(曲线强度/横向抖动/抖动频率) + 开火配置（多条：热键+类别）
- 自动开火：激活热键/触发/连发模式/冷却/延迟/开火方式
- 连点：触发按键 + 基础按下时间 + 基础间隔时间
- 自动背闪：启用 + 类别配置（随机方向/躲避/转身距离/步数/冷却/等待）
- 准星找色：主/副按键 + ROI 宽高 + 3 组颜色槽（启用+7色选择）

## 05 模型库（model-page）
- 本地模型库：可用数 + 当前模型 + 列表（名称/尺寸/类别数/加密/游戏档）
- 导入模型弹窗：格式选择（RKNN/ONNX/HEF/远端ONNX）+ 模型文件/类别标签文件/预设参数文件/校准图 + 游戏标签 + 描述 + 导入
- 连接 Windows 电脑：输入局域网 IP 连接
- 模型类别：编辑类别名称
- 模型操作：切换/删除/绑定预设/游戏配置/并发数/RKNN帧格式

## 06 显示与鼠标（hardware-page）
- 显示器模式：环出模式开关 + 显示检测框/类别/粗细/配色 + 首选模式（EDID 模式列表）+ 仅输出首选模式 + 环出颜色格式（RGB888/BGR888）+ 显示器名称/厂商代码/产品ID
- USB 鼠标硬件信息：VID/PID/描述符/协议
- 下载USB诊断日志 / 刷新硬件

## 07 Hailo-8 加速（hailo-page）
PCIe 插卡/内核驱动/HailoRT/设备扫描/当前内核/芯片温度 + 依赖安装进度

## 08 键鼠盒子（kmbox-page）
测试画圈 + 5 协议配置卡：kmboxNet / CatNet / MAKCU / Ferrum / kmboxB+（每卡：启用 + 参数 + 保存配置自动连接）

## 09 网络配置（wifi-page）
- Wi-Fi / AP 热点切换 + 扫描/连接/重置默认
- 局域网名称/访问端口（改端口重启提示）
- 局域网黑名单：扫描设备/拉黑/清除

## 10 预设参数（preset-page）
- 预设列表 + 保存（新预设名）+ 加载 + 重命名 + 清理未使用
- 导入预设弹窗 + 导出
- 当前自动保存目标

## 11 主题商店（theme-store-page）
主题列表/预览/兑换码/安装

## 12 系统状态（license-page）
- 设备授权：激活状态/永久授权/授权修复
- 系统更新：检查更新/切换版本/安装进度
- 存储容量：扩容/刷新
- 风扇控制：全速运行 + 温度来源（自动/SoC/CPU大核/GPU/NPU/Hailo）+ PWM接口/当前温度/风量/转速反馈
- 公告/免责声明

## 全局交互元素
- Toast（右上角成功/失败）
- 弹窗（modal：导入/激活/预设/主题）
- 状态徽章 pill（待机/运行中/未读取/已激活）
- field 结构：`<label class=field><span class=field-label>中文名</span><input data-config><span class=field-hint>白话说明</span></label>`
- switch 结构：`<label class=switch><input type=checkbox data-config><span></span></label>`
- range 滑块与 number 输入框联动（`id_range` 绑定）
- data-config 属性 = 所有控件自动收集 → PUT /api/config 保存
