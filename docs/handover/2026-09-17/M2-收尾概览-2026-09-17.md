## 一句话原理

授权 = **离线 Ed25519 签名卡**（自包含 TweetNaCl，**零 OpenSSL、零新 NEEDED** ⇒ 出货向量 AUTH=OFF 不变、A32 ELF 闭集不破）。
语义 **fail-closed**：无卡 = AI 关（透传/Web 管理照常）；坏卡 / 他板卡 / 过期卡 / 篡改卡**一律拒且不落盘**；
有效卡经 web `/api/license/activate` → IPC `ACTIVATE_LICENSE` → core 验签 → 落盘 `license.json` → 重启由恢复链恢复。

## 本轮修掉 / 清掉

- **F0（真缺陷，已修）**：发布树 `usbproxy/usb-proxy` 丢可执行位 ⇒ usbproxy 服务 failed。根因 = 预编译 ELF 无 shebang ⇒ MSYS 判非可执行（源侧 0644）⇒ tar 原样进 payload；而发布门禁的 unit 断言**只查 `ExecStart` 首 token、不查它内部 exec 的二进制** ⇒ 静默穿过。**已修在 `scripts/ttbox_fhs_init.sh`**（显式 `chmod 0755` + 成因注释），重发布后 5 服务全 active。**换新板 / OTA 首装必现 ⇒ 商业化阻断项。**
- **F1（环境陷阱，已清）**：板端残留非法 `/etc/ttbox/license.key` **遮蔽 store** ⇒ 激活当次绿灯、重启回落未激活（恢复链"覆盖优先"是**设计如此**）。已备份 `/root/license-backup-20260917T062241Z/` 并改 `*.v1-retired`。
