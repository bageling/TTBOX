## 6. 待查（**根因未知，有复发风险**）

- 现象特征：**多个不同仓库**的 pack 同时出现在回收站 ⇒ 这不是 git 自身行为，而是**某次外壳级"清理 .git / 清理磁盘空间"操作**在 08:23:41 触发。
- 建议排查方向（**业主侧**）：
  1. Windows「存储感知 / 磁盘清理」是否被开启并清理过开发目录；
  2. 第三方清理工具（CCleaner 类）或杀软是否把 `*.pack` 当垃圾/威胁处置；
  3. 是否有自动化任务在清理大文件（本环境支持自动化任务）；
  4. 回收站中其余 pack 的原始路径（`$I*` 元数据文件）可反查是哪些仓库被动过。
- **在根因查清前**：建议对代码仓做**仓外/机外备份**（`git bundle` 单文件即可），因为「无 remote、禁 push」意味着当前**唯一的对象副本就在这块盘上**。
